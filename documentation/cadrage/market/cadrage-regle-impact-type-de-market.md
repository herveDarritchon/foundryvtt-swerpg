# Synthèse MJ — Acheter, vendre et trouver des objets dans Star Wars: Aux Confins de l’Empire

## 1. Principe général

Dans Star Wars: Aux Confins de l’Empire, chaque objet important possède généralement plusieurs informations utiles :

- un **prix** en crédits ;
- une **rareté** ;
- parfois la mention **(R)**, pour “Restricted”, c’est-à-dire objet restreint ;
- un **encombrement** ;
- des caractéristiques mécaniques selon le type d’objet : dégâts, critique, portée, défense, encaissement, emplacements de modifications, attributs, etc.

Le prix indique combien l’objet coûte dans des conditions normales.
La rareté indique à quel point il est difficile de le trouver.
La mention (R) indique qu’il ne s’agit pas d’un achat légal standard : l’objet relève du marché noir, d’un contrôle impérial, d’un trafic local ou d’un réseau spécialisé.

La règle importante à retenir est simple :
**le prix dit combien ça coûte ; la rareté dit s’il est possible de le trouver.**

## 2. La rareté : l’échelle de disponibilité

La rareté va de **0 à 10**.

- **0–1** : objet courant, facile à obtenir.
- **2–3** : objet commun mais pas forcément disponible partout.
- **4–5** : objet standard mais demandant de chercher un fournisseur.
- **6–7** : objet spécialisé, militaire, exotique ou peu distribué.
- **8–9** : objet très rare, dangereux, illégal ou réservé à certains milieux.
- **10** : objet exceptionnel, quasi introuvable sans intrigue dédiée.

En jeu, lorsqu’un PJ cherche un objet, le MJ peut demander un test pour savoir s’il trouve un vendeur. Pour un objet légal, on utilise généralement **Négociation**. Le MJ peut parfois autoriser une compétence de Connaissance adaptée, par exemple Mondes du Noyau, Bordure Extérieure, Pègre ou Éducation.

## 3. La rareté dépend du lieu

La rareté de base n’est pas absolue. Elle est modifiée par l’endroit où se trouvent les PJ.

Exemples de logique :

- sur Coruscant, Corellia ou un grand monde du Noyau, beaucoup de biens technologiques sont plus faciles à trouver ;
- sur un monde civilisé ou une colonie, les objets courants restent accessibles ;
- dans la Bordure Extérieure, les objets spécialisés deviennent plus difficiles à obtenir ;
- dans l’Espace Sauvage ou sur un monde peu développé, même du matériel relativement banal peut devenir rare.

Pour ta campagne autour de Tatooine, Mos Shuuta, les Hutts et les marges impériales, la règle pratique est :

**un objet civil de base peut se trouver assez facilement ; un objet militaire, spécialisé, impérial, médical avancé ou de contrebande doit devenir une scène.**

## 4. Objets légaux et objets restreints

Il faut distinguer deux cas.

### Objet légal

Un objet légal est acheté normalement : le PJ cherche un vendeur, négocie éventuellement, puis paie le prix demandé.

Exemples :

- comlink ;
- vêtements renforcés ;
- sac à dos ;
- trousse à outils ;
- medpac ;
- scanner ;
- équipement de survie ;
- pièces mécaniques communes.

Le MJ peut demander un test de Négociation si l’objet n’est pas immédiatement disponible ou si les PJ veulent le trouver rapidement, moins cher, en quantité ou dans un lieu isolé.

### Objet restreint (R)

Un objet marqué **(R)** est restreint. Il compte comme objet de marché noir.

Exemples typiques :

- armes militaires lourdes ;
- explosifs ;
- drogues et épices illégales ;
- poisons ;
- matériel d’infiltration sensible ;
- équipement impérial volé ;
- codes de sécurité ;
- droïdes ou composants interdits ;
- technologie rare ou artefacts sensibles.

Pour trouver ce type d’objet, on utilise généralement **Système D / Pègre / Streetwise** selon la traduction et la table. La difficulté dépend de la rareté, mais aussi du niveau de surveillance locale.

Sur Tatooine, un blaster illégal peut être assez accessible si l’on connaît les bons intermédiaires. Sur un monde impérial très contrôlé, le même achat peut attirer le BSI, les douanes ou un indicateur.

## 5. Effet de la rareté sur le prix

La règle de base est claire : **la rareté sert d’abord à déterminer la difficulté pour trouver l’objet, pas automatiquement à recalculer son prix.**

Cependant, le MJ peut ajuster le prix si la situation le justifie :

- monde isolé ;
- pénurie ;
- guerre ;
- blocus impérial ;
- monopole hutt ;
- marchandise volée ;
- urgence ;
- achat discret ;
- vendeur hostile ;
- demande inhabituelle ;
- très bon ou très mauvais résultat au test.

Pour garder le jeu fluide, mieux vaut éviter de recalculer tous les prix. Utilise plutôt les résultats narratifs :

- Avantages : meilleur état, petit rabais, munitions incluses, livraison discrète, vendeur fiable.
- Menaces : prix gonflé, objet usé, délai, vendeur bavard, surveillance, dette implicite.
- Triomphe : contact durable, objet supérieur, information bonus, accès à un réseau.
- Désastre : arnaque, embuscade, objet tracé, intervention impériale, dette envers un Hutt.

## 6. Vente d’objets

Les PJ ne revendent presque jamais un objet au prix plein.

En règle pratique :

- réussite simple : environ **25 %** du prix ;
- bon résultat : environ **50 %** ;
- très bon résultat : jusqu’à **75 %** ;
- prix plein : seulement si le contexte est très favorable, ou si l’objet est exceptionnel.

Pour les objets illégaux, la vente passe aussi par le marché noir. Cela peut rapporter, mais c’est risqué : acheteur criminel, indicateur, douanes, dette, arnaque ou trahison.

## 7. Commerce, contrebande et transport de cargaison

Les règles de commerce deviennent plus intéressantes lorsqu’il ne s’agit plus d’acheter un blaster, mais de transporter une cargaison.

Exemple :

- acheter des pièces mécaniques sur Corellia ;
- les revendre sur un monde isolé de la Bordure Extérieure ;
- transporter du ryll, des armes ou des pièces de droïdes ;
- profiter d’un blocus ou d’une pénurie.

Dans ce cas, la différence de rareté entre le lieu d’achat et le lieu de revente peut modifier la valeur commerciale. Mais ce système sert surtout aux scénarios de contrebande, pas aux achats ordinaires de personnages.

Pour une campagne Edge, c’est une excellente base pour créer des missions :

- transporter une cargaison légale mais convoitée ;
- passer une cargaison illégale sous contrôle douanier ;
- livrer des armes à une cellule rebelle ;
- revendre une cargaison volée à un Hutt ;
- découvrir que la marchandise est piégée, marquée ou vivante.

## 8. Les grandes catégories d’objets

### Armes

Les armes regroupent les armes de tir, armes de mêlée, armes lourdes, armes explosives, armes exotiques et, selon les gammes, armes liées à la Force.

Elles sont souvent sensibles en termes de légalité. Un pistolet blaster peut passer inaperçu dans la Bordure Extérieure, mais un détonateur thermique, un fusil militaire ou un lance-missile attirera forcément l’attention.

### Armures et protections

Elles incluent les vêtements renforcés, armures de combat, armures spécialisées, combinaisons environnementales, protections lourdes ou discrètes.

Certaines armures civiles sont légales. Les armures militaires, impériales ou spécialisées peuvent poser problème.

### Équipement général

C’est la catégorie la plus utile pour les PJ :

- comlinks ;
- datapads ;
- jumelles ;
- scanners ;
- medpacs ;
- trousses à outils ;
- respirateurs ;
- cordes synthétiques ;
- filtres d’eau ;
- équipements de survie ;
- matériel de sécurité ;
- matériel d’infiltration.

Ce sont souvent les meilleurs achats pour rendre les PJ plus compétents sans augmenter uniquement leur puissance de combat.

### Drogues, poisons et consommables

Cette catégorie est très intéressante en campagne Edge, car elle touche à la pègre, aux Hutts, aux mines de ryll, au trafic d’épices et aux dettes.

Beaucoup de ces objets sont restreints. Même lorsqu’ils ont un prix faible, leur achat ou leur possession peut être dangereux.

### Cybernétiques

Les implants et membres cybernétiques sont souvent coûteux, rares, médicaux ou contrôlés. Ils peuvent nécessiter non seulement de l’argent, mais aussi un chirurgien, une clinique, un atelier, un réseau criminel ou un contact corporatiste.

### Droïdes et composants

Les droïdes peuvent être des biens ordinaires, des outils, des compagnons ou des marchandises sensibles. Les droïdes militaires, assassins, impériaux, modifiés ou dotés de logiciels interdits doivent être traités comme des achats risqués.

### Modifications et accessoires

Les accessoires d’armes, d’armures, de véhicules et de droïdes ne sont pas de simples bonus. Ils peuvent demander :

- un achat ;
- une installation ;
- un test de Mécanique ;
- des pièces ;
- un atelier ;
- parfois un contact spécialisé.

### Véhicules et vaisseaux

Les véhicules et vaisseaux ont aussi un coût et une rareté. Mais en pratique, ils dépassent souvent le simple achat.

Acheter un vaisseau implique aussi :

- immatriculation ;
- transpondeur ;
- dettes ;
- entretien ;
- carburant ;
- droits de stationnement ;
- douanes ;
- licences ;
- attention des autorités ou des criminels.

Un vaisseau est rarement “juste un objet”. C’est un moteur de campagne.

## 9. Application à Tatooine et aux territoires hutts

Dans une campagne située autour de Tatooine, Mos Shuuta et les Hutts, le marché doit être vivant, instable et dangereux.

Un objet peut être :

- disponible mais hors de prix ;
- disponible mais volé ;
- disponible mais en mauvais état ;
- disponible seulement via un intermédiaire hutt ;
- disponible contre une faveur plutôt que des crédits ;
- disponible mais traçable ;
- indisponible légalement, mais trouvable au marché noir ;
- introuvable sans partir en mission.

Les Hutts ne contrôlent pas “le marché” comme une administration unique. Ils contrôlent des réseaux, des dettes, des fournisseurs, des transporteurs, des receleurs et des protections. Acheter un objet rare chez eux signifie souvent acheter aussi une relation dangereuse.

## 10. Procédure simple pour le MJ

Quand un PJ veut acheter un objet, pose quatre questions :

1. **Est-ce légal ici ?**
2. **Est-ce rare ici ?**
3. **Qui peut le vendre ?**
4. **Qu’est-ce que cela coûte vraiment : crédits, dette, risque ou service ?**

Puis applique :

- objet courant et légal : achat simple ;
- objet rare mais légal : test de Négociation ou Connaissance ;
- objet illégal : test de Pègre / Système D / Streetwise ;
- objet très rare : transforme l’achat en scène ou en mission ;
- objet dangereux pour la campagne : rends-le disponible, mais avec un coût narratif.

## 11. Table pratique MJ

| Situation                      | Test conseillé                   | Conséquence principale         |
| ------------------------------ | -------------------------------- | ------------------------------ |
| Acheter un objet courant       | Aucun test ou Négociation facile | Achat normal                   |
| Trouver un objet rare légal    | Négociation ou Connaissance      | Disponibilité, délai, prix     |
| Trouver un objet illégal       | Pègre / Système D / Streetwise   | Contact, risque, marché noir   |
| Revendre un objet légal        | Négociation                      | 25 %, 50 % ou 75 % du prix     |
| Revendre un objet illégal      | Pègre / Streetwise               | Argent + risque criminel       |
| Acheter en territoire hutt     | Négociation, Pègre ou Charme     | Prix, dette, faveur            |
| Acheter sous contrôle impérial | Négociation ou Pègre avec risque | Contrôle, permis, dénonciation |
| Acheter en urgence             | Test plus difficile              | Prix augmenté, choix réduit    |
| Acheter en grande quantité     | Scène commerciale                | Logistique, cargaison, douanes |

## 12. Règle maison recommandée pour fluidifier

Pour une campagne Edge, utilise cette règle simple :

- **Réussite** : l’objet est disponible au prix normal.
- **Avantages** : remise, accessoire, bonne qualité, vendeur fiable, information utile.
- **Menaces** : prix +10 à +25 %, délai, objet abîmé, témoin gênant, dette mineure.
- **Triomphe** : contact durable, objet supérieur, livraison discrète, piste de scénario.
- **Désastre** : piège, arnaque, objet marqué, intervention impériale, dette envers un criminel.

Cela respecte l’esprit du système : le marché n’est pas seulement une boutique, c’est une source d’histoires.

## 13. À retenir

Le système d’objets dans Star Wars Edge repose sur trois idées :

1. **Le prix mesure la valeur économique.**
2. **La rareté mesure la difficulté à trouver l’objet.**
3. **La légalité mesure le risque narratif.**

Un bon marché Edge ne doit pas seulement répondre “oui/non”.
Il doit répondre : “oui, mais…”, “oui, si…”, ou “oui, et maintenant quelqu’un sait que vous le cherchez.”
